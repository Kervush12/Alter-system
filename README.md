# Alter System

**Modern Dynamic Island style desktop widget for Windows 10/11.**

A lightweight, customizable floating hub for your desktop that brings essential widgets and system tools right to the edge of your screen.

## ✨ Features

- **🕒 Clock & Weather** — Current time, date, and weekly weather forecast.
- **🎵 Media Controls** — View current track info and control playback.
- **📊 System Monitor** — Real-time CPU/GPU load and temperature tracking.
- **⏱️ Built-in Timer & Calculator** — Quick access without opening extra windows.
- **🎨 Deep Customization** — Acrylic/Mica blur, accent colors, opacity, glow effects, and free positioning along screen edges (with vertical mode).
- **⚡ Smart & Lightweight** — Automatically hides when apps go fullscreen, supports global hotkeys, runs smoothly at 165Hz+, and uses minimal RAM (~100–190 MB).
- **🌍 Multi-language** — Built-in support for 4 languages.
